# 毛啟明作品集

**[打开 3D 作品房间](https://wittlud7.github.io/)** · [千禧个人小站](https://wittlud7.github.io/home.html)

真正的 Three.js 3D 房间：拖动转动视角、缩放、点物件或编号查看九个项目。每个项目可直达 GitHub 源码与运行说明；已有 GitHub Pages 演示的作品还提供在线入口。手机支持清单浏览，WebGL 失败时保留全部作品清单。

## 作品

- [场边](https://github.com/wittlud7/sidecourt-sports-lab)：体育数据、资料比较与模拟工作台。
- [观物](https://github.com/wittlud7/guanwu-museum-journeys)：博物馆内容、路线与 AI 伴游。
- [方块漫游](https://github.com/wittlud7/block-wander)：艺术消除小游戏。
- [电商经营 BI](https://github.com/wittlud7/ecommerce-bi-agent-demo)：商品与渠道分析；[GitHub Pages 演示](https://wittlud7.github.io/ecommerce-bi-agent-demo/)。
- [商品销售预测与库存策略](https://github.com/wittlud7/supply-chain-planning-lab)：需求回测、库存与产能实验。
- [行意](https://github.com/wittlud7/used-car-growth-agent)：二手车咨询 Agent 原型。
- [回声](https://github.com/wittlud7/echo-renaissance)：书影音记录、关联与创作工具。
- [小理](https://github.com/wittlud7/xiaoli-ai-brain)：资料检索、引用与复习工作台。
- [出版 AI 方案](https://github.com/wittlud7/publishing-ai-opc-concept)：交互商业方案；[GitHub Pages 演示](https://wittlud7.github.io/publishing-ai-opc-concept/)。

## 发布与运行

本仓库为无构建步骤的静态网站。`index.html` 为房间，`home.html` 为千禧小站。GitHub Pages 使用 main 分支根目录发布。

本地可运行 `python3 -m http.server 8842`，再打开 http://localhost:8842/ 。全部页面、模型、脚本与图片来自本仓库，不从 ChatGPT 网站加载或跳转。

作品房间完全运行在浏览器。其他仓库的模型 API、登录、云数据库或服务端排行榜不属于 GitHub Pages 的静态托管能力；请按各仓库说明运行服务，不在本页面假装提供服务器能力。
